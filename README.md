# Financial Path & DCA Simulator v4

## v4
- 左1/5を設定サイドバー化。指数/積立で中心シナリオと周辺本数を共通利用。
- 中心シナリオに ◀ / ▶。押すと1本移動して即再描画。
- prepared data は `USE prepared data ▼` 直下にプルダウン表示。
- ヒストグラムのビン統計はグラフ内ポップアップ表示。
- ビン統計の%表示は 0–10% / 90–100% のみ小数1桁、それ以外は整数。
- 中心シナリオをヒストグラム内に紫色▼で表示。
- 時系列グラフの中心パスをクリックすると `日数 (年数)` と値をグラフ内表示。
- 対数補助目盛 2/4/6/8 にも小さな数値ラベル。
- 主/補助グリッドを濃く変更。
- DCA初期値: 頭金0、1回額=`積立間隔 / CSV行数` を有効数字3桁（step0から積立）。
- 色設定UIを対象別5行（中心/周辺/中央値/平均/信頼区間）へ整理。
- 信頼区間は塗り透過度と縁線透過度を別設定。
- 設定はlocalStorageに保存。

## prepared data
`simulation_data/manifest.json`:

```json
{
  "files": [
    {"file": "gbm.csv", "label": "GBM μ=7%, σ=18%"}
  ]
}
```

GitHub Pagesは静的配信のためフォルダ一覧を自動列挙できず、manifest方式を使います。
