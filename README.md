# Financial Path & DCA Simulator v5

v4を基にしたUI・描画改善版です。

## v5 主な変更

- 時系列グラフの右Y軸にも左Y軸と同じ目盛り・数値を表示。
- 時系列X軸を営業日stepではなく、252営業日=1年として `0年 / 5年 / 10年 / ...` 表示。
- CSV入力・prepared dataを左サイドバーから上部ヘッダー右側へ移動。
- ヘッダー高さを約1.5倍へ拡張。
- CSVドラッグ&ドロップ欄を薄い緑色へ変更。
- 左サイドバーの設定を関連項目ごとに横並び化:
  - 中心シナリオ + 前後本数
  - 信頼区間 + 中央値 + 平均値
  - 頭金 + 積立間隔 + 1回積立額
  - 初回積立 + 積立グラフ表示モード
  - 表示反映 + 色・線設定
  - 積立再計算 + 期間総額1への自動設定
- 中心シナリオの ◀ / ▶ を青色ボタン化。
- 色・線設定モーダルで透過度列を広めに確保し、2項目横並び時の可読性を改善。
- グラフ内ツールチップを拡大し、文字サイズを約1.5〜2倍へ変更。
- JS/CSS URLを `?v=5` に更新してキャッシュ混在を軽減。

## prepared data

`simulation_data/manifest.json` に公開CSV一覧を記載します。

```json
{
  "files": [
    {"file": "gbm.csv", "label": "GBM μ=7%, σ=18%"}
  ]
}
```

GitHub Pagesへは本ZIP内のファイル一式をそのまま配置できます。
